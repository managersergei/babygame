# Реле «игра → Telegram»

Бот присылает родителю, какие слова ребёнок проговорил и сколько звёзд собрал. Токена бота в игре нет:
события уходят на этот Worker вместе с кодом привязки, а он уже пишет в Telegram.

## Как это работает

1. Игра генерирует код из 10 знаков и хранит его в `localStorage` (`babygame.tg`).
2. На экране «Родителям» (кнопка ⓘ) показывается QR и ссылка `https://t.me/<бот>?start=<код>`.
3. Родитель жмёт Start — бот получает `/start <код>` и запоминает в KV пару код ↔ chat_id.
4. Игра шлёт `POST /ev` с кодом и сводкой (слова, звёзды, машинка) — Worker находит chat_id и отправляет сообщение.
5. `/stop` в боте стирает привязку.

Что уходит: код привязки, слова из уроков, число звёзд, название машинки. Ни голоса, ни записей, ни ключей.

## Развёртывание с нуля (если понадобится другой бот)

1. Создать бота у @BotFather → получить токен, запомнить username.
2. Зарегистрироваться в Cloudflare (бесплатный план) и создать KV-хранилище:
   ```bash
   ./wrangler.sh login
   ./wrangler.sh kv namespace create LINKS
   ```
   Полученный `id` вписать в `wrangler.toml`.
3. Положить секреты и выкатить:
   ```bash
   ./wrangler.sh secret put BOT_TOKEN        # токен от BotFather
   ./wrangler.sh secret put WEBHOOK_SECRET   # любая строка от 16 знаков
   ./wrangler.sh deploy
   ```
4. Один раз зарегистрировать вебхук и команды бота:
   ```bash
   curl "https://<адрес-воркера>/setup?key=<WEBHOOK_SECRET>"
   ```
5. В `index.html` заполнить две константы рядом с секцией 17e:
   `TG_BOT` — username бота без «собаки», `TG_API` — адрес воркера. Пустые значения выключают функцию целиком.

### Грабли

* `npx` не находится в обычном терминале владельца — поэтому здесь лежит `wrangler.sh`:
  он добавляет Homebrew в PATH и запускает локальный wrangler из `node_modules`.
* У свежего аккаунта Cloudflare нет поддомена `workers.dev`, и `deploy` падает с предложением
  зарегистрировать его. Без TTY wrangler отвечает «нет» сам и выходит с ошибкой; регистрируется
  один раз через `PUT /accounts/<id>/workers/subdomain`.
* Сертификат нового поддомена выпускается не мгновенно — первые минуты curl отвечает
  ошибкой TLS-рукопожатия. Это не поломка, нужно подождать и повторить.

## Проверка без Telegram

`DRY=1` в переменных окружения: Worker не пишет в Telegram, а возвращает текст сообщения в ответе.
Локально: `./wrangler.sh dev` и `curl -X POST localhost:8787/ev -d '{"c":"ABCDEFGHJK","sum":{"words":{"ПРЫЖОК":2},"stars":7}}'`.

## Лимиты бесплатного плана

100 000 запросов в сутки у Worker, 1000 записей в сутки у KV. Игра шлёт не чаще одного сообщения
в несколько минут плюс сводку в конце сессии, так что запас многократный.

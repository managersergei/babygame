# Инструкция по работе с этим проектом

## ⚠️ Игра собирается из src/ — index.html правит только сборщик (с 18.09.2026)

`index.html` — **результат сборки**, а не исходник. Любая правка руками в нём
пропадёт при следующем `npm run build`.

* исходники: `src/index.template.html` (вёрстка и стили) и `src/js/*.js` (41 модуль);
* порядок склейки: `src/build.json`;
* собрать: `npm run build` → перезаписывает `index.html`;
* собранный `index.html` **коммитится** — GitHub Pages раздаёт репозиторий как есть;
* `node tools/build.mjs --check` проверяет, что собранный файл не разошёлся с `src/` (это же делает CI).

Проверки: `npm test` (нужен playwright, ставится `npm install`). Полный круг — около
20 минут: `balance` моделирует 240 с игры, `rhythm` — 300 с. Это нормально, не зависание.

Настройки игры (`TUNE`, `LN`, `PHYS`, `WEIGHT`, `SIM`) правятся не в коде, а админкой:
`?admin=1` или Ctrl+Shift+A. Кнопка «Выгрузить tune.js» отдаёт файл, который кладут
в корень и коммитят — только тогда правки уезжают всем.

**Перед любым изменением в проекте — прочитать [ГРАБЛИ.md](ГРАБЛИ.md).**
Там разбор ошибок, которые в этом проекте уже повторялись по нескольку раз. Особенно раздел
«ОШИБКИ, КОТОРЫЕ ПОВТОРЯЛИСЬ ПО 2–4 РАЗА» — это чек-лист, а не история.

## Обязательные проверки перед тем, как сказать «готово»

1. **Озвучка.** Правил реплику — прогнать сквозную сверку: все строки внутри `A.say(...)`
   в `index.html` должны иметь mp3 в `assets/voice/` (имя = FNV-1a хеш точного текста,
   список — `assets/voice/list.js`). Расхождение не даёт ошибки в консоли, игра молча
   переключается на робо-голос браузера.
2. **Направление спрайтов.** Добавил или перегенерил движущийся ассет — сверить силуэт с базовым
   спрайтом и с его зеркалом программно. Глазом уже ошибались четыре раза.
3. **Скриншот из игры.** Не из превью и не из контактного листа. «Почти нормально» = «нет».
4. **Замены по подстроке.** Каждый якорь должен встречаться ровно один раз — проверить `grep -c`
   до правки, иначе одна осечка отменит весь пакет.

## Принципы, о которых просил владелец

* Развилка, которая меняет **форму** работы (а не её реализацию), — вопрос владельцу, а не
  собственное решение. Второй провал подряд — стоп и пересмотр допущения, а не третья попытка.
* Слова в игре — только настоящие, игра учит речи. Выдуманные подмены не предлагать.
* Фразы для трёхлетнего — короткие. Текст на экранах он читать не умеет: всё важное говорит диктор.

## Ключи и внешние API (владелец, 08.09.2026, строго)

* **Запрещено** использовать API-ключи проекта «монетка» (`~/Documents/pf/.env`, `FAL_KEY`) в этом проекте — ни для картинок, ни для озвучки, ни «на один запрос». Нарушение уже было 08.09.2026 (сториборды и 4 реплики), повторять нельзя.
* Генерация визуалов — через бесплатные сервисы и роутер `~/Documents/инструменты/freegen` (см. его README). Платные ключи — только те, что владелец выдал явно для этого проекта.
* Ключи не хранить в репозитории (он публичный: github.com/managersergei/babygame). Только `.env` вне репо с правами 600, значения не печатать в вывод.

# Телеграм-бот с отчётами о прогрессе: пошагово

Бот присылает родителю, какие слова ребёнок проговорил и сколько звёзд собрал. Токена бота в игре нет:
игра шлёт события на маленькое реле в Cloudflare, а оно уже пишет в Telegram. Весь путь занимает
минут пятнадцать и денег не стоит.

## Шаг 1. Создать бота (2 минуты)

1. Откройте в Telegram чат с **@BotFather**.
2. Отправьте `/newbot`.
3. Имя бота — любое, например `Машинки: прогресс`.
4. Username — должен заканчиваться на `bot`, например `mashinki_progress_bot`. Запомните его.
5. BotFather пришлёт строку вида `1234567890:AA...` — это **токен**. Его никому не показывайте
   и мне не присылайте, он понадобится только на шаге 3, вы вставите его сами.

## Шаг 2. Аккаунт Cloudflare (3 минуты)

1. Зарегистрируйтесь на dash.cloudflare.com (бесплатный план, карта не нужна).
2. Больше в панели ничего делать не надо: всё остальное сделают команды ниже.

## Шаг 3. Выкатить реле (5 команд)

Откройте терминал и выполните по очереди. Все команды — из папки `~/Documents/babygame/tg`.

```bash
cd ~/Documents/babygame/tg
./wrangler.sh login
```

> `wrangler.sh` — маленький запускатель: он сам находит Node, поэтому работает в любом терминале,
> даже если `npx` не находится. Всё остальное — как обычно: откроется браузер, разрешите доступ.
Откроется браузер, разрешите доступ. Дальше:

```bash
./wrangler.sh kv namespace create LINKS
```
Команда напечатает строку с `id = "..."`; этот id вписывается в `wrangler.toml`.
**Сделано 09.09.2026** — хранилище создано, id уже в файле, шаг можно пропустить.

```bash
./wrangler.sh secret put BOT_TOKEN
```
Вставьте токен от BotFather, нажмите Enter.

```bash
./wrangler.sh secret put WEBHOOK_SECRET
```
Придумайте и вставьте любую строку от 16 знаков (например, случайный набор букв и цифр). Запомните её.

```bash
./wrangler.sh deploy
```
В конце команда напечатает адрес вида `https://babygame-tg.ваш-аккаунт.workers.dev` — это **адрес реле**.

## Шаг 4. Разбудить бота (одна команда)

```bash
curl "https://babygame-tg.ваш-аккаунт.workers.dev/setup?key=ВАША_СТРОКА_ИЗ_ШАГА_3"
```
Ответ должен содержать `"ok":true`. Это включает вебхук и команды бота.

## Шаг 5. Включить в игре

Пришлите мне две строки, и я впишу их в игру:
* username бота без собаки, например `mashinki_progress_bot`;
* адрес реле, например `https://babygame-tg.ваш-аккаунт.workers.dev`.

Или впишите сами в `index.html`, рядом строки 4491:
```js
var TG_BOT  = 'mashinki_progress_bot';
var TG_API  = 'https://babygame-tg.ваш-аккаунт.workers.dev';
```

## Шаг 6. Привязать телефон

Откройте игру, нажмите ⓘ «Для родителей» — появится QR-код и ссылка. Наведите камеру телефона
или нажмите ссылку, в открывшемся чате нажмите Start. Через несколько секунд под кодом появится
«Telegram привязан ✓».

## Что будет приходить

* «🗣 Сказал ПРЫЖОК — 3 из 5» по ходу игры, но не чаще раза в три минуты;
* «🎉 Выучил слово ПРЫЖОК!» когда слово освоено;
* сводка в конце сессии: сколько звёзд, какие слова, сколько раз не доехал.

Выключить — команда `/stop` в чате с ботом. Данные: только код привязки, слова, звёзды и название
машинки. Ни голоса, ни записей, ни ключей туда не уходит.

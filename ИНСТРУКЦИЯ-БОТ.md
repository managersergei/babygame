# Телеграм-бот с отчётами о прогрессе

Бот присылает родителю, какие слова ребёнок проговорил и сколько звёзд собрал.

**Всё уже настроено и работает. От вас нужен один шаг — Шаг 1.**

Бот: **@big_drive_bot** («Big Drive»). Реле: `https://babygame-tg.bigdrive.workers.dev`
(Cloudflare Worker, бесплатный план). Настроено 09.09.2026.

## Шаг 1. Привязать телефон (30 секунд)

1. Откройте игру: https://managersergei.github.io/babygame/
2. Нажмите ⓘ в правом верхнем углу, там кнопка **«Для родителей»**.
3. На экране появится QR-код и ссылка. Наведите камеру телефона на QR — откроется чат с ботом.
   Если играете с телефона, просто нажмите ссылку.
4. В чате нажмите **Start** (или отправьте `/start`).
5. Через несколько секунд под кодом в игре появится **«Telegram привязан ✓»**.

Всё. Дальше отчёты приходят сами.

## Что будет приходить

* «🗣 Сказал ПРЫЖОК — 3 из 5» по ходу игры, но не чаще раза в три минуты;
* «🎉 Выучил слово ПРЫЖОК!» когда слово освоено;
* сводка в конце сессии: сколько звёзд, какие слова, сколько раз не доехал.

Выключить — команда `/stop` в чате с ботом, включить обратно — снова `/start` по той же ссылке.

Уходят только код привязки, слова, звёзды и название машинки. Ни голоса, ни записей, ни ключей
туда не попадает: токена бота в игре нет, игра шлёт события на реле, а уже реле пишет в Telegram.

## Если привязка не сработала

* **QR не появился.** Значит не догрузилась библиотека QR — ссылка под кодом работает всегда,
  нажмите её или перешлите себе в Telegram.
* **Бот молчит после Start.** Проверьте, что открыли ссылку с кодом целиком
  (`https://t.me/big_drive_bot?start=XXXXXXXXXX`), а не просто чат с ботом: без кода бот
  не знает, к какой игре привязываться.
* **«Telegram привязан ✓» не появилось.** Игра переспрашивает реле раз в 15 секунд первые пару
  минут; перезагрузите страницу игры.

## Приложение: как это устроено и как переделать

Нужно, только если понадобится другой бот или другой аккаунт Cloudflare. Обычному пользованию
это не требуется.

Секреты лежат **вне репозитория**, в `~/.config/babygame/tg.env` (права 600):
`TG_BOT_USERNAME`, `BOT_TOKEN`, `WEBHOOK_SECRET`. В git они не попадают.

Что где настроено:

| Что | Значение |
|---|---|
| Аккаунт Cloudflare | sergeyyurich.p@gmail.com |
| Поддомен workers.dev | `bigdrive` |
| Воркер | `babygame-tg` |
| Хранилище KV | `LINKS`, id в `tg/wrangler.toml` |
| Секреты воркера | `BOT_TOKEN`, `WEBHOOK_SECRET` |
| Разрешённый источник | `https://managersergei.github.io` |
| Константы в игре | `TG_BOT`, `TG_API` в `index.html`, раздел 17e |

Полная последовательность для нового бота — в [tg/README.md](tg/README.md):
создать бота у @BotFather, `./wrangler.sh login`, `kv namespace create LINKS`,
`secret put BOT_TOKEN`, `secret put WEBHOOK_SECRET`, `deploy`, затем один раз
`curl "<адрес реле>/setup?key=<WEBHOOK_SECRET>"` — он регистрирует вебхук и команды бота.

Грабли, на которые уже наступали:

* `npx` не находится в обычном терминале — поэтому в папке `tg` лежит `wrangler.sh`,
  он сам добавляет Homebrew в PATH и запускает локальный wrangler.
* Новый аккаунт Cloudflare не имеет поддомена `workers.dev`, и `deploy` падает с
  предложением зарегистрировать его. Регистрируется один раз, после этого адрес
  вида `<воркер>.<поддомен>.workers.dev` работает.
* Сертификат для только что созданного поддомена выпускается не мгновенно: первые
  минуты curl отвечает ошибкой TLS-рукопожатия. Это нормально, надо подождать.

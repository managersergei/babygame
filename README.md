# МАШИНКИ — игра для малышей (3 года)

Демо: выбор машинки → выбор режима → бесконечная поездка. Всё управление — **ПРОБЕЛ** и **← →**.

## Запуск

```bash
cd ~/Documents/babygame
python3 -m http.server 8765
```

Открыть http://127.0.0.1:8765/ (можно и просто двойным кликом по `index.html`).

## Экраны

1. **Гараж** — `← →` листают 10 машинок, `ПРОБЕЛ` — дальше.
2. **Режим** — `← →` выбирают, `ПРОБЕЛ` — поехали:
   * **ТОЛЬКО ПРОБЕЛ** — машинка едет сама, ребёнку нужна одна кнопка;
   * **СО СТРЕЛКАМИ** — `→` газ, `←` тормоз, `ПРОБЕЛ` прыжок.
3. **Поездка** — звёзды, шарики, конусы, лужи, трамплины, радужная арка каждые 10 звёзд.

**Бензин.** Тратится по мере езды, канистры лежат по дороге (гарантированно раз в ~1100 px).
Кончился — машинка мягко останавливается, экран «БЕНЗИН ЗАКОНЧИЛСЯ», `ПРОБЕЛ` — заправиться и ехать дальше.
Проигрыша нет, звёзды не сгорают.

Кнопки внизу дублируют клавиши (для тача). Мелкие кнопки справа снизу: 🏠 гараж, 🔊 звук (клавиша `M`), ⛶ полный экран.
`Esc` — вернуться в гараж.

## Отладка

`index.html?s=garage|mode|play|empty|name|lesson|repair|camp` — сразу нужный экран.
Ещё: `&dbg=1` — оверлей со стейтом и трассой переходов, `&fast=N` — ускорение времени в N раз,
`&w=jump|fuel|light` — какой урок, `&st=N` — с какого уровня кампании, `&ph=` — фаза мастерской.

## Графика

Спрайты сгенерированы через fal.ai (`flux/dev`), фон и запечённая тень вырезаны скриптом.

```bash
export FAL_KEY='...'
python3 tools/gen_sprites.py            # всё, что ещё не скачано в assets_raw/
python3 tools/gen_sprites.py fire star  # только эти
```

* `assets_raw/` — исходные PNG от нейросети (не удалять: повторная обработка идёт из них, без новых запросов к API);
* `assets/` — обрезанные прозрачные спрайты, их грузит игра.

Звук целиком синтезируется в WebAudio (мотор, сирена, гудок, монетки), голос — `speechSynthesis`
(если в системе нет русского голоса, озвучка молча отключается).

## Голосовой режим

Третий режим на экране выбора. Порядок уровней и слов — в **[LEVELS.md](LEVELS.md)**.

Кратко: знакомство («как тебя зовут?» ×3) → короткая гонка, где учим **ПРЫЖОК** у ямы →
мастерская с вопросом «сколько колёс?» → гонка со словом **БЕНЗИН** → мастерская →
гонка со словом **ФАРА** → и так по кругу. Одно новое слово за этап; выученное слово
сразу работает как живая команда.

Распознавание своё, офлайн: игра запоминает, как слово звучит у конкретного ребёнка
(спектр + DTW), а не пытается разобрать русскую речь. Образцы — в `localStorage`.
Микрофон спрашивается при первом нажатии клавиши; отказ или кнопка 🚫 просто отключают
голос — всё проходится пробелом.
